Дамп данных с SPI-Flash микросхемы парилки PAFOS. У которой TFT-экранчик и ракета, которая показывает, что ты на кумаре.
Данные микросхемы и бинарника, которые создала ИИ-шка: 
### 1. `vape_4mb.bin` (4096 КБ) — Умная одноразка "PAFOS" (2024)
* **Чип памяти:** Giantec Semiconductor `GT25Q32A` (32 Мбит / 4 МБ SPI Flash, корпус TSSOP-8 0.65 мм).
* **Контент:** Полный графический интерфейс современного вейпа с цветным дисплеем 80x160.
* **Формат графики:** Сырой несжатый **RGB565** (16-bit color, Little-Endian).
* **Смещение идеального кадра ракеты:** `743197` (разрешение $80 \times 160$, шаг между кадрами 25 600 байт).
* **Найденные ассеты:** Анимация полета ракеты, турбо-режим, кольцевой спидометр заряда/жидкости, экран блокировки `OFF`, логотип `PAFOS`.
### 2. Файлы:
* **'sprite_tuner_v2.py'** - интерактивный GUI-тюнер на Tkinter для поиска спрайтов, подбора ширины/высоты и точной фазы байт.
* **'dump_vape.py'** - непосредственно программа-дампер, которая при помощи RP2040-Zero спыздила все 4мб с микросхемы
* **'build_gif_v...'** - мои попытки при помощи иишки создать гифку
* **То, что в папке dumper_dvd_old** - дамп с древней микросхемы от двдшника, проба пера, но там ничего интересного нет.
